# Brands — لوگو و رنگ‌های سازمانی

همه‌ی لوگوها مستقیم از سایت رسمی هر برند گرفته شده‌اند (۵ اکتبر ۲۰۲۶ / ۱۳ مهر ۱۴۰۵).
رنگ‌ها از داخل خود فایل لوگو و متغیرهای CSS سایت استخراج شده‌اند.

- **Primary** = رنگ اصلی برند (رنگ لوگو)
- **Secondary / Accent** = رنگ‌های مکمل یا رنگ دکمه‌ها و UI سایت
- همه‌ی فایل‌ها SVG یا PNG با پس‌زمینه‌ی شفاف هستند.
